Map Maker

Edits data/map/island.json, the file the game builds the island from. Your work autosaves in this browser.

  • Select V: tap anything to edit it on the right. Drag handles to reshape; drag a selected object to move it. Empty drag pans, wheel/pinch zooms.
  • Road R: tap points, Enter or Done to finish. Ends snap onto other roads so junctions blend.
  • Land L: drag an outline to draw an island anywhere in the sea. Coast C pushes the main island's shore in or out.
  • Buildings B: pick a type and tap or paint. Houses face the nearest road. Church, plaza, market and gas stations can be added or moved; the ground under them is levelled. New in 11.45: two-storey house, bahay na bato, bungalow, sari-sari store, fish stall, resort cottage, resort hotel (with pool), warehouse, chapel and lighthouse. Chapel, lighthouse, warehouse and resort are placed one at a time; the rest paint like houses.
  • Multi-select M or hold Shift: tap items to add them, drag empty space for a box. Move them together, delete them, or Merge roads into one. A selected road point can Split the road.
  • Del deletes the selected point (or object), Ctrl Z / Ctrl Shift Z undo/redo, F fits the island, Esc deselects.

Working together

  • Everyone starts from the official map, edits, then ☰ → Save project and sends the .cpmmap.json file.
  • Merge takes any number of project files and applies each person's changes onto your map (added, moved and deleted roads, features, vehicles, coast). If two people changed the same thing, yours stays and you can pick theirs.
  • Test ride opens the game on your map (only in this browser). Export for game gives the island.json to commit, or save it as data/map/<name>.json and play it with ?map=<name>.

Town blocks still generate their shophouse rows automatically (drawn as blocks). Bigger maps mean a bigger terrain grid, so islands far out make loading slower on phones.
