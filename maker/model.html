Help

Side / Front / Top: drag a part to move it (snaps to 5 mm, hold Shift for free), drag empty space to pan, wheel to zoom. 3D: drag to orbit, right-drag to pan.

Panel = a side outline made solid: select it in the Side view and drag its yellow points. Double-click near an edge adds a point, right-click a point removes it.

Mirror (M) draws a copy on the other side (x negated): build one side of the bike, get both.

Group: what the part moves with in the game (bike: steer = turns with the bars, slider = fork lowers, rear = rear wheel hub).

Paint follows the player's paint colour in the game; light / tail / amber glow with the lamps.

Keys: Del delete, Ctrl+D duplicate, arrows nudge 1 cm, Ctrl+Z/Ctrl+Y, F fit, Esc deselect, 1-4 views.

Save writes data/models/<id>.json when the page runs on node tools/serve.mjs, otherwise it downloads the file. The bike side: README "Model Maker".
